# Лабораторная работа №1: архиватор логов

Лабораторную выполнили Мизонова Ксения, Малышева Арина, Лысова Дарья. В проект входят архиватор старых файлов для Linux, автоматические тесты к нему и версия архиватора для Windows.

## Состав проекта

| Файл | За что отвечает |
| --- | --- |
| `archive_logs.sh` | Основной Bash-скрипт: проверяет заполненность папки и архивирует старые файлы. |
| `test_archive.sh` | Создаёт тестовые данные и автоматически проверяет работу Bash-скрипта. |
| `archive_logs.bat` | Версия архиватора для Windows. |
| `.gitignore` | Не позволяет добавить в Git тестовые данные и созданные архивы. |
| `README.md` | Краткое описание проекта и команды запуска. |

## Как работает архиватор

Скрипт получает папку с файлами, папку для архивов, порог заполненности в процентах и условный лимит папки в МиБ. Процент считается как размер всех файлов, делённый на этот лимит. Bash-версия учитывает файлы во всех вложенных папках.

Если порог превышен, скрипт выбирает самые старые файлы, создаёт архив и затем удаляет выбранные исходные файлы. Если порог не превышен, файлы остаются на месте. Обычный формат архива — `.tar.gz`; при `LAB1_MAX_COMPRESSION=1` Bash-версия создаёт `.tar.lzma`.

## Запуск

На Ubuntu из папки проекта:

```bash
bash archive_logs.sh "./logs" "./backups" 70 600
LAB1_MAX_COMPRESSION=1 bash archive_logs.sh "./logs" "./backups" 70 600
bash test_archive.sh
```

Здесь `70` — порог в процентах, `600` — условный лимит в МиБ. Для режима LZMA нужна команда `lzma`.

В Windows:

```bat
archive_logs.bat "C:\logs" "C:\backups" 70 600
```

Для первого запуска используйте тестовые файлы: при превышении порога архиватор удаляет исходные файлы после создания архива.
